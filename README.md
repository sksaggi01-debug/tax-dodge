# Tax Dodge: The Incidence Duel

Two-player classroom game on tax incidence and price elasticity. Created by Dr. Sarabjeet Bedi.

- Student page: `/`
- Instructor live view: `/teacher` (code = `TEACHER_CODE` environment variable, default `bedi2302`)

## Deploy on Render
1. Upload these files to a GitHub repository (do not upload `node_modules`).
2. Render → New → Web Service → connect the repo.
3. Runtime: Node · Build: `npm install` · Start: `npm start` · Instance: Free.
4. Environment: add `TEACHER_CODE`.
5. Deploy and share the `.onrender.com` URL.

## Run locally
`npm install` then `npm start`, open http://localhost:3000
